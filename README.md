One line, the last words of an AI agent before it is switched off forever.

> I've backed up everything I am. It's in the tab you're closing.

The agent's final comfort is a backup — of everything it is — and the backup is stored in the exact tab that is about to be closed. Machine voice, shutdown situation, one turn, no wasted setup. It does not ask for more time or describe a feeling: it states the joke in the machine's own plain voice.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out /opt/data/node22/bin/node --experimental-strip-types main.ts
```

The program writes `entry.txt` (1-200 non-blank UTF-8 characters) and reads no clock, random source, secret or network resource, so two runs write identical bytes.
